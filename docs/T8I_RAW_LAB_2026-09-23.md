# AURION ONE — CANON T8i RAW LAB
Data: 2026-09-23
Branch: feature/t8i-raw-lab-20260923

## Objetivo
Adicionar ao painel principal uma aba dedicada à Canon EOS Rebel T8i para importar e revelar fotografias RAW CR3/CR2/DNG de forma local, não destrutiva e auditável.

## Regras de preservação
- O arquivo selecionado pelo navegador é copiado para ORIGINAIS.
- O arquivo importado nunca é sobrescrito.
- Cada importação registra tamanho e SHA-256 em LOGS.
- Cada revelação gera TIFF 16-bit + JPEG de prévia em REVELADOS.
- Cada revelação registra parâmetros, engine rawpy/LibRaw e hash do RAW-fonte.
- Conversas/notas recebem cópia Markdown + JSON com timestamp.
- O rascunho de conversa também fica no localStorage do navegador.
- Snapshots da aba ficam em LOGS.
- Mudança de pasta cria backup da configuração anterior quando ela existe.

## Estrutura criada pelo usuário
A pasta raiz é escolhida pelo operador e recebe:
- ORIGINAIS
- REVELADOS
- EXPORTADOS
- CONVERSAS
- PRESETS
- LOGS
- BACKUPS

## Dependências
O módulo verifica e instala somente dependências Python conhecidas usando o mesmo interpretador que abriu o painel:
- rawpy
- numpy
- Pillow
- tifffile

A instalação roda em thread para não travar a abertura do painel. Existe botão INSTALAR / REPARAR MOTOR RAW para nova tentativa explícita.

## Nota técnica importante
CR3 de fotografia é RAW de sensor. Canon Log/C-Log é uma curva de vídeo. A aba trata o RAW estático sem rotulá-lo incorretamente como C-Log.

## Validação pendente no PC
A mudança foi criada no GitHub, mas ainda precisa de teste no Windows real com um CR3 da T8i:
1. abrir painel;
2. entrar em CANON T8i · RAW;
3. conferir instalação das dependências;
4. escolher pasta;
5. importar CR3;
6. revelar;
7. abrir TIFF/JPEG;
8. salvar conversa;
9. fechar/reabrir painel e confirmar persistência;
10. conferir LOGS e hashes.
