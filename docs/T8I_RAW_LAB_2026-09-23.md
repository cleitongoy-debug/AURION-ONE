# Canon T8i RAW Lab — AURION ONE

Data: 2026-09-23  
Branch: `feature/t8i-raw-lab`

## Objetivo
Adicionar ao AURION ONE uma área dedicada à Canon T8i para organizar originais, revelar arquivos RAW `.CR3`, salvar cópias processadas, manter sidecars e registrar as conversas/notas da sessão sem sobrescrever o original.

## Correção técnica importante
`.CR3` é o contêiner RAW fotográfico da Canon. Nesta aba ele **não é tratado como Canon Log/C-Log**. O fluxo implementado é de revelação RAW fotográfica. Vídeo Log deve ser tratado em um módulo de vídeo separado.

## Rotas
- `/one/t8i`: interface do laboratório.
- `/api/t8i/config`: configuração e estado das dependências.
- `/api/t8i/install-dependencies`: instalação explícita das dependências Python. Só pode ser chamada no próprio PC.
- `/api/t8i/pick-folder`: abre seletor nativo de pasta no Windows local.
- `/api/t8i/create-folder`: cria subpastas dentro dos locais configurados.
- `/api/t8i/files`: lista arquivos suportados na pasta de originais.
- `/api/t8i/preview`: gera prévia.
- `/api/t8i/develop`: salva cópia processada.
- `/api/t8i/file`: entrega apenas arquivos gerados nas pastas autorizadas.
- `/api/t8i/conversations`: salva/lista conversas.
- `/api/t8i/conversations/load`: reabre conversa salva.

## Dependências
A aba declara e pode instalar explicitamente:
- rawpy
- numpy
- Pillow
- imageio
- tifffile

Nada é instalado no F5 e nada é instalado silenciosamente no boot.

## Estrutura criada ao escolher PASTA-MÃE
- `01_ORIGINAIS`
- `02_PREVIEWS`
- `03_EXPORTADOS`
- `04_CONVERSAS`
- `05_PRESETS`
- `06_SIDECARS`
- `07_LOGS`

O usuário também pode apontar cada depósito para outra pasta existente e pode criar subpastas pela interface.

## Preservação
- Originais não são sobrescritos.
- Revelação gera uma nova saída.
- Cada saída recebe sidecar JSON com parâmetros.
- Eventos principais entram em `remote-agent/data/t8i_lab/manifest.jsonl`.
- Conversas são salvas em JSON e Markdown por escrita atômica.
- O texto em edição também usa rascunho local do navegador.

## Ajustes implementados
- exposição
- contraste
- saturação
- temperatura aproximada
- matiz aproximada
- sombras
- realces
- exportação TIFF 16-bit
- exportação JPEG qualidade 95
- prévia JPEG reduzida

## Segurança
- instalação de dependências e seletor nativo de pasta são bloqueados para clientes remotos;
- leitura/escrita é limitada às raízes escolhidas;
- nomes de subpastas são higienizados;
- nenhum original é deletado ou movido automaticamente.

## Limites ainda não testados
Código preparado no GitHub não equivale a execução validada no Windows. É necessário testar no PC:
1. instalação de wheels do `rawpy` no Python usado pelo AURION;
2. leitura real de um CR3 da Canon T8i;
3. TIFF 16-bit por `imageio+tifffile`;
4. seletor Tk no ambiente gráfico do Windows;
5. preview e download via painel;
6. gravação/reabertura de conversa.

Se `rawpy` não reconhecer um CR3 específico, registrar o arquivo/câmera/erro e atualizar LibRaw/rawpy de forma controlada, sem converter o original às cegas.
