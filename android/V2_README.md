# AURION ONE V2 · Android 6.0.0

Build aditiva para o POCO. Mantém o applicationId `one.aurion.mobile.superstudio` e aumenta versionCode para 60.

## Implementado nesta branch
- editor local de imagem JPEG/PNG/WebP com brilho, contraste, saturação, temperatura e tinta;
- pasta de trabalho escolhida pelo Android Storage Access Framework;
- memória local SQLite e backup JSON na pasta escolhida;
- cofre de credenciais via Android Keystore para GitHub/Hugging Face/token do PC;
- diagnóstico local;
- teste de conexão com PC;
- aba T8i/RAW que seleciona CR3 sem fingir revelado nativo; desenvolvimento CR3 completo permanece no módulo PC V2;
- LAB persistido na memória.

Vídeo/áudio avançado Android e Google OAuth completo não são marcados como concluídos nesta build.
